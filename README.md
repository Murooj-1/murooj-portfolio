# ملف أعمال مروج الزهراني

موقع بالعربية والإنجليزية باستخدام HTML وCSS وJavaScript دون اعتماديات بناء، مع تبديل RTL/LTR وحفظ اللغة المختارة. الترجمات في dist/language.js، وتنسيق الإنجليزية وزر اللغة في dist/language.css. تحسينات الجوال في dist/mobile.css.

التصميم داكن، بخط Cairo للعناوين وTajawal للنصوص. تظهر هوية مروج واسمها في الواجهة، مع تدرجات الأزرق المخضر والأصفر والرمادي، وحركات التمرير وتفاعل الماوس. يمكن إيقاف الحركة من التذييل، وتُحترم إعدادات تقليل الحركة في النظام.

المحتوى في dist/index.html، التنسيق الأساسي في dist/editorial.css، تحديثات المظهر وإمكانية الوصول في dist/dark.css، والهوية والحركة في dist/refined.css وdist/motion.js، والتفاعلات في dist/app.js.


للمعاينة، افتح dist/index.html محليًا.
